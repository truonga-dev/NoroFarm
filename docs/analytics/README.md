# Chiến lược Phân tích Dữ liệu (Analytics Guidelines)

## Mục tiêu
Dữ liệu là mạch máu của mọi nền tảng số. Thư mục `docs/analytics` định nghĩa cách NoroFarm thu thập, đo lường và phân tích hành vi của người dùng (Nông dân, Thương lái, Doanh nghiệp xuất khẩu) để từ đó đưa ra các quyết định Cải tiến Sản phẩm (Product-led Growth) và Chiến lược Kinh doanh.

## Khác biệt giữa Analytics và Monitoring
- **Monitoring (DevOps):** Đo lường "Sức khỏe hệ thống" (Server CPU, RAM, API Response Time, Lỗi Database). Phục vụ cho Developer. (Xem tại `docs/devops`).
- **Analytics (Business):** Đo lường "Hành vi người dùng" (Có bao nhiêu người đọc bài viết A, Tỷ lệ thoát trang là bao nhiêu, Bao nhiêu người đăng ký VIP). Phục vụ cho Product Manager và Marketing.

## Tổ chức Tài liệu
Thư mục này sẽ quy chuẩn hóa:
1. Công cụ sử dụng (GA4 cho Tổng quan, PostHog cho Product Analytics).
2. Danh sách Sự kiện (Events Dictionary).
3. Các chỉ số đo lường hiệu quả cốt lõi (KPIs).
4. Phễu chuyển đổi (Conversion Funnels).
