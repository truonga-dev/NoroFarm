# Color Palette (Bảng màu Thương hiệu)

Bảng màu NoroFarm bao gồm các dải màu được căn chỉnh kỹ lưỡng (Color tokens) giúp duy trì sự thống nhất trên toàn hệ thống UI.

## 1. Màu Chính (Primary Color)
Đại diện cho nông nghiệp, sinh thái và sự sống.
- **NoroFarm Emerald:** 
  - Mã màu HEX: `#10B981` (Dùng cho nút chính, logo)
  - Hover/Active: `#059669`
  - Subtle (Nền nhạt): `#D1FAE5`

## 2. Màu Phụ (Secondary Color)
Dùng cho các thành phần thứ yếu để không tranh giành sự chú ý với màu chính.
- Màu: Xám trung tính ánh xanh (`Slate`).
  - Base: `#64748B`
  - Hover: `#475569`
  - Background: `#F1F5F9`

## 3. Màu Semantic (Trạng thái)
Phản ánh thị trường (Giá lên/xuống) và trạng thái hệ thống.

### Success (Giá tăng / Hoàn thành)
- Base: `#22C55E` (Green)
- Ứng dụng: Nhãn (+2%), Nút lưu thành công.

### Error (Giá giảm / Lỗi)
- Base: `#EF4444` (Red)
- Ứng dụng: Nhãn (-1.5%), Thông báo lỗi 404/500.

### Warning (Cảnh báo)
- Base: `#F59E0B` (Amber)
- Ứng dụng: Cảnh báo bão/thời tiết xấu, Thông báo chú ý.

## 4. Màu Trung tính (Neutral Colors)
Dùng để xây dựng khung xương của website (Typography, Background, Borders).

### Light Mode
- **Nền chính (Bg):** `#FFFFFF` (True White)
- **Nền phụ (Surface):** `#F8FAFC` (Slate-50)
- **Văn bản chính:** `#0F172A` (Slate-900)
- **Văn bản mờ (Muted):** `#64748B` (Slate-500)
- **Viền (Border):** `#E2E8F0` (Slate-200)

### Dark Mode
- **Nền chính (Bg):** `#020617` (Slate-950) hoặc `#0A0A0A`
- **Nền phụ (Surface):** `#0F172A` (Slate-900) hoặc `#171717`
- **Văn bản chính:** `#F8FAFC` (Slate-50)
- **Văn bản mờ (Muted):** `#94A3B8` (Slate-400)
- **Viền (Border):** `#1E293B` (Slate-800)
